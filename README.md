# Mega Advance India

Professional React + Vite + Tailwind CSS frontend for Mega Advance India.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

- Course data is centralized in `src/data/courses.js`.
- Contact details are intentionally placeholders because no official contact details were supplied.
- The logo mark is based on the supplied Growth Bharat reference screenshot. The text is rendered separately as `Mega Advance India`, making the branding easy to replace later.
- Photography uses remote Unsplash image URLs. Replace them with client-approved/local assets before production if required.
- No unsupported placement percentages, hiring-partner claims, testimonials, student counts, fees, accreditation or guaranteed-job claims are included.
